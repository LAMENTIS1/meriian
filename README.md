# meriian - Ingenspark Platform

Autonomous AI Intelligence, Data Connectors, Segmentations, and Optimization Workspace.

## Project Structure
- **Ingen Connect**: Integration fabric, CDC pipelines & streaming webhooks.
- **Ingen Data**: Vector repository, dataset chunking, and document RAG.
- **Ingen Customer**: Decile, Quartile, Trend, Dominant, Look-Alike, Combine & Customer 360° analytics.
- **Ingen Optim**: Causal A/B Testing wizard, Marketing Mix Modeling (MMM), and Performance Drivers.
- **Ingen Tracker**: Interactive Chart and Dashboard Creator & Saver.

## Getting Started
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```
